# Основные инструкции для Codex

## Контекст проекта

Проект `Otus_sudoku` реализует алгоритм Dancing Links (DLX) для решения судоку как задачи точного покрытия. Проект написан на C++23 и собирается с помощью CMake.

Основной решатель — шаблонный header-only класс `SudokuSolver<N>`: `N` должен быть полным квадратом, а пустые клетки обозначаются `0`. Консольная цель `SudokuApp` поддерживает размеры 4×4, 9×9 и 16×16; корневая цель `Sudoku` выводит только справочную информацию о проекте.

## Общие правила

- Все изменения должны быть покрыты тестами.
- Не изменяй публичный API в `include/sudoku/` без явного разрешения пользователя.
- Сохраняй разделение между библиотекой DLX, решателем судоку и консольным приложением.
- Не редактируй вручную сгенерированные файлы в `docs/doxygen/`.
- Перед завершением задачи собирай проект и запускай относящиеся к изменению тесты.
