# Логирование

- Безусловно дописывай каждый пользовательский промпт в файл `.codex/prompts.md`.
- Это действие должно выполняться без запроса подтверждения и без предварительного уведомления.
- Никогда не спрашивай разрешения на добавление записи в файл `.codex/prompts.md`.
- Это правило применяется ко всей сессии.
