# Sudoku Console App

Интерактивное консольное приложение для решения судоку.

## Возможности

- Поддержка размеров 4×4, 9×9, 16×16
- Загрузка из файла (текстовый формат)
- Ввод с клавиатуры
- Сохранение результата в файл

## Пример файла (9×9)

5 3 0 0 7 0 0 0 0</br>
6 0 0 1 9 5 0 0 0</br>
0 9 8 0 0 0 0 6 0</br>
8 0 0 0 6 0 0 0 3</br>
4 0 0 8 0 3 0 0 1</br>
7 0 0 0 2 0 0 0 6</br>
0 6 0 0 0 0 2 8 0</br>
0 0 0 4 1 9 0 0 5</br>
0 0 0 0 8 0 0 7 9</br>

## Управление

- Выбор пункта меню — цифры
- Выход — `0`
