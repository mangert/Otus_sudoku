# Sudoku Console App

Интерактивное консольное приложение для решения судоку.

## Возможности

- Поддержка размеров 4×4, 9×9, 16×16
- Загрузка из TXT- и JSON-файлов
- Ввод с клавиатуры
- Сохранение результата в TXT- или JSON-файл

## Формат TXT

Файл содержит `N` строк по `N` целых чисел, разделённых пробелами:

```
5 3 0 0 7 0 0 0 0
6 0 0 1 9 5 0 0 0
0 9 8 0 0 0 0 6 0
8 0 0 0 6 0 0 0 3
4 0 0 8 0 3 0 0 1
7 0 0 0 2 0 0 0 6
0 6 0 0 0 0 2 8 0
0 0 0 4 1 9 0 0 5
0 0 0 0 8 0 0 7 9
```

## Формат JSON

Для исходных и решённых досок используется одна JSON-схема:

```json
{
  "size": 4,
  "board": [
    [1, 0, 0, 4],
    [0, 4, 1, 0],
    [0, 1, 4, 0],
    [4, 0, 0, 1]
  ]
}
```

Требования к формату:

- корень — объект ровно с полями `size` и `board`;
- порядок полей произвольный, повторные и неизвестные поля запрещены;
- `size` — положительное целое число, совпадающее с выбранным размером;
- `board` содержит ровно `N` массивов по `N` целых чисел;
- значения клеток находятся в диапазоне `0..N`;
- разрешены пробелы, переводы строк и табуляция;
- комментарии, trailing comma, дробные числа, экспоненты, экранированные имена полей и данные после корневого объекта запрещены.

Пустые клетки в обоих форматах обозначаются `0`. Формат файла выбирается отдельным пунктом меню; расширение автоматически не определяется и не добавляется.

## Меню

После выбора размера приложение предлагает источник данных:

1. загрузить из TXT-файла;
2. загрузить из JSON-файла;
3. ввести с клавиатуры.

После вывода решения доступны действия:

1. сохранить в TXT-файл;
2. сохранить в JSON-файл;
3. решить другую головоломку.

В каждом меню пункт `0` завершает работу приложения.

## Управление

- Выбор пункта меню — цифры
- Выход — `0`
